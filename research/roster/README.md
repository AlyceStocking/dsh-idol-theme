## 数据及复现

`index.json` 保存范围；每位偶像一个 JSON，记录页面修订、查询时间、明确的 infobox 文件前缀、姓名罗马字及图片元数据。不保存人物介绍或游戏台词。

```sh
node scripts/audit-roster.mjs
npm run build:characters
npm run build:client
npm run check
npm test
```

采集脚本最多 4 个角色并行，每批最多 50 个 imageinfo 标题，每个请求有 20 秒超时。成功的角色结果默认复用；失败项重试。HTTP 429/567 会停止新网络请求；请等待服务恢复后再运行，不连续重试。`--refresh` 显式重新采集全部角色。

构建脚本完全离线，并对图标、四姿态顺序、256×256 尺寸、图片 MIME、CDN URL 和默认背景进行筛选。保持雪美旧服装顺序和默认值以兼容偏好。名单搜索支持中文、罗马字及词序交换。

角色目录约 1.38 MB，生成的浏览器客户端约 1.41 MB，均为未压缩文件大小。仍使用同一套设置组件，仅当前角色创建图片选项；独立桌宠的预热范围、4 请求并发和 32 项缓存上限保持不变。

## 验证边界

100 项自动化测试通过，包括范围恰为 190、未就绪角色不能被选择、全部可用角色逐一切换与偏好恢复，以及旧有通知、加载竞态和缓存上限检查。

本次采集和检查验证的是 **BWiki 元数据与代码结构**，不是 7,400 张小人图逐张下载/解码或 188 位角色逐个桌面目视验收。原双角色 Windows 预览结果仍仅覆盖雪美/爱丽丝。正式 DSH 插件尚未替换。
