# Windows 双角色试验

> 后续进展：2026-10-14 收录范围扩展至 190 位，目前 188 位可选、2 位待收录。见 [190 位收录报告](roster/README.md)。下文为双角色阶段的实现记录。

2026-10-13；版本 `1.3.0-desktop.1`。基于原仓库 main `4b162a3`，仅向新公开仓库 `AlyceStocking/dsh-idol-theme` 同步修改。

## 本轮实现

- 同一套设置面板增加姓名/罗马字搜索和角色下拉菜单。当前选中角色即使不匹配搜索仍保留，避免选项与实际状态脱节。
- 雪美 13 套、爱丽丝 14 套服装，每套四姿态；分别使用各自的背景、签名和 Mobamas 清单。保持现有配色和素材尺寸规则。
- 点击台词、提醒台词全部为 `。。。。。`。会话标题、设置和加载错误提示保留功能性文字。
- 切换角色时一起更新角色、服装、姿态和背景，保留签名/Mobamas 开关；目前回到某角色使用其默认服装/背景，不记忆每个角色上一次搭配。
- 桌宠在新小人下载、解码完成后提交切换；失败保留旧小人，可重新选择重试。过期请求不能覆盖较新的选择。
- 桌面磁盘偏好保存 characterId、稳定 outfitId/poseId/backgroundId，并兼容老的仅索引偏好。已删除的稳定 ID 回落默认素材。
- 输入或选择角色时，设置面板不会被原有 15 秒自动关闭打断。

## 为 100+ 角色保留的扩展路径

`lib/characters.js` 是共享注册表和偏好规则，Host、网页和 Electron 都从它取数据。`scripts/build-client.mjs` 生成网页内嵌清单，避免手工复制。Yukimi 保留旧素材顺序以兼容已存索引，其余角色由 `scripts/build-characters.mjs` 生成。

增加普通角色的步骤：

1. 在 `scripts/audit-bwiki.mjs` 的样本列表增加 id、BWiki 页面名和文件名 stem。按批运行，不要一次无界请求所有角色。
2. 检查 `research/bwiki-samples.json` 的 missing、每套姿态和文件分类；有缺项时先记录，不用其他角色的图补位。
3. 在构建脚本 aliases 表补充检索别名；运行 `npm run build:characters` 和 `npm run build:client`。
4. 执行 `npm run check`、`npm test`，打包后预览新角色。

运行时不访问 BWiki API、不按名字猜 CDN 哈希。注册表不限定角色个数，也不为每个角色创建组件/计时器。新增角色沿用现有数据格式和交互；不规则文件名或缺图仍需目录适配。

加载策略：

- 名单只含文字；角色 URL 元数据目前随模块一起加载，尚未拆成按角色动态模块。100+ 角色需评估元数据体积和启动解析耗时，但不会因此下载全部图片。
- 桌宠只预热当前角色的当前及下一套服装（本次为最多 8 张）；最多 4 张并行解码。
- sprite cache 最多保留 32 项，最近访问优先保留；切换后取消旧角色尚未开始的后台预热。已开始的请求允许结束或在 12 秒后超时。
- 32 张 256×256 小人的原始 RGBA 约 8 MiB；这不是整个 Electron 进程/GPU/浏览器磁盘缓存的总内存上限。命中透明度缓存另限 32 项。
- 仅创建当前角色服装和背景选项，预览图继续使用原有 `loading="lazy"`。背景仍为原图 URL，打开/滚动列表时可能下载较大的原图；未做缩略图服务。
- 网页备用小人的加载逻辑仍沿用原网页实现；上述解码预加载和有界 sprite cache 是 Windows 独立桌宠路径。

## 只记录、不进行的人工精修

| 项目 | 后续需要确认/精修的内容 |
| --- | --- |
| 背景 | 人脸遮挡、裁切焦点、不同宽高比和默认卡面选择 |
| 小人 | 透明留白、视觉大小、脚底基线、动作顺序是否需要角色特例 |
| 签名 | 各角色签名长宽比、位置、亮度与可读性 |
| 文案 | 角色专属语气、各类提醒台词；本轮一律占位 |
| 配色 | 专属配色和阅读对比度；本轮保留现有色板 |
| 素材 | 例外命名、缺图/错图、重定向、画质、素材授权及来源标注复核 |

没有逐张人工修图、调整布局参数或编写角色台词。

## 验证与交付边界

- Node 测试涵盖原有生命周期/会话提醒，以及双角色原子切换、旧偏好迁移、稳定 ID 恢复、跨角色 URL 拒绝、加载失败/竞态、网页背景/签名联动和 300 张模拟素材的缓存上限。
- 已成功打包 Windows Electron 应用；实际隔离预览中观察到雪美切换为爱丽丝、服装名单更新、`tachibana` 检索仅列出爱丽丝及占位气泡。
- 未逐张在线加载所有卡图；未做 100+ 真实角色性能测试。
- 本轮没有替换用户已安装的 DSH 主题，真实 DSH 会话的端到端联动尚未复测。预览提醒来自模拟事件；点击真实会话跳转不应据此宣称已重新验证。
- 保留旧插件 ID、RPC 通道和默认数据目录以兼容；两版本不能并行启用。独立预览使用 `build/preview-data/`，不会覆盖正式桌宠偏好。
